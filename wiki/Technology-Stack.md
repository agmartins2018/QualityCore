| Tecnologia | Uso |
|---|---|
| Java 21 | Linguagem do backend |
| Spring Boot 3.5.6 | Aplicação web e APIs |
| Spring Web | Controllers HTTP |
| Spring Validation | Validação de entrada |
| Spring Data JPA | Persistência |
| H2 | Banco de dados local |
| REST Assured 5.5.6 | Biblioteca de suporte a chamadas HTTP/testes |
| JUnit / Spring Boot Test | Testes automatizados |
| Maven | Build e dependências |
| HTML5 / CSS / JavaScript | Frontend |
| k6 | Execução de testes de performance |
| JWT HS256 | Tokens de autenticação |
| PBKDF2-HMAC-SHA256 | Hash de senhas |

## Observações

- O frontend é servido como conteúdo estático pelo Spring Boot.
- O projeto não utiliza React; a interface está implementada com HTML, CSS e JavaScript.
- A versão do k6 pode depender do binário disponível/obtido no ambiente. O histórico de validação menciona k6 2.3.0.
