# Visão do produto

## O que é o QUALITYCORE?

QUALITYCORE é uma plataforma web local para apoiar atividades de API Quality Engineering. Seu escopo atual combina testes funcionais, execução de fluxos, monitoramento sintético, testes de contrato e testes de performance.

## Objetivos

- Centralizar configurações e resultados de testes de API.
- Reutilizar API Tests em diferentes Collections.
- Acompanhar disponibilidade e latência de alvos monitorados.
- Verificar respostas reais contra contratos declarados.
- Avaliar comportamento de APIs sob carga com k6.
- Disponibilizar histórico e relatórios para análise.

## Público-alvo

- QA Engineers e Analistas de Testes.
- SDETs e profissionais de automação.
- Quality Engineers.
- Desenvolvedores que precisam validar APIs.
- Equipes que desejam experimentar testes sintéticos e performance localmente.

## Escopo e posicionamento

O produto está classificado como MVP local. Não deve ser apresentado como serviço SaaS multi-tenant, plataforma de observabilidade completa ou ambiente de produção endurecido.
